# Learn Validation Guide

Use this guide for new Learn tickets. Shared rules are in `SHARED_BASE_SCHEMA.md`.

## Creation

Require a Topic, Learning Goals, Explanation, Resources, and Check Preference. Ask the user whether a knowledge check is useful and record the choice.

## Resolution

Require Takeaways and an optional-check outcome. Record results for completed
checks. Record the user's choice and reason for skips. A defer stays open.

Require three checkable criteria. Put each on a separate line and use IDs
starting at `AC001:`.
